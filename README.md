# KRYPTA - Financial Crime Intelligence Platform

KRYPTA is a hackathon prototype demonstrating suspicious transaction detection, financial network analysis, explainable risk indicators, and counterfactual intervention simulation.

## Core Features
- Transaction risk analysis
- Suspicious activity monitoring
- MoneyTrail network visualisation
- Account-level investigation
- Financial Crime Digital Twin
- Counterfactual intervention scenarios
- Exportable investigation reports

## Technology
Frontend: React, Vite, Tailwind CSS, Recharts, Framer Motion.
Backend: Python, FastAPI, Pandas, NumPy, NetworkX, Scikit-learn.

## API
- GET /
- GET /api/health
- GET /api/intelligence/analyse
- GET /api/digital-twin/simulate

## Limitations
This prototype uses synthetic demonstration transactions. Risk scores and intervention outputs are illustrative, not proof of criminal activity or validated predictions of prevented financial loss. KRYPTA is not connected to real banking systems.
